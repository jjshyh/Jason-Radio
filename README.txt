# 제이슨 라디오 PWA

## 구성 파일
- `index.html`: 라디오 플레이어 본체
- `manifest.webmanifest`: 홈 화면 앱 설치 정보
- `sw.js`: 앱 화면의 오프라인 캐시 및 업데이트 처리
- `icon.svg`, `icon-192.png`, `icon-512.png`: 앱 아이콘

## 설치 전제
PWA 설치를 위해서는 HTTPS가 적용된 웹호스팅이 필요합니다. PC의 로컬 파일을 직접 여는 `file://` 방식으로는 앱 설치가 정상 작동하지 않습니다.

## 배포 방법
1. 이 폴더의 파일을 모두 웹호스팅의 같은 폴더에 업로드합니다.
2. `https://도메인/폴더/` 주소로 갤럭시 스마트폰 삼성 인터넷 또는 Chrome에서 접속합니다.
3. 브라우저 메뉴에서 '현재 페이지 추가' → '홈 화면' 또는 '앱 설치'를 선택합니다.
4. 홈 화면에 생성된 '제이슨 라디오' 아이콘으로 실행합니다.

## 채널 관련 주의
기존 소스에 있던 10개 스트림 주소는 그대로 유지했습니다. 주소 제공 서버(radio.bsod.kr)는 방송국 공식 서버가 아닌 외부 중계 주소일 수 있으므로, 각 채널의 실제 재생 가능 여부와 지속성은 서버 운영 상태 및 방송국 정책에 따라 달라집니다. 이 프로그램은 스트림을 자체 제공하거나 우회하지 않습니다.
새 채널은 방송사/서비스가 허용한 HTTPS 스트리밍 URL을 직접 입력해 추가할 수 있습니다. HLS(.m3u8) 등은 브라우저·서버의 CORS 및 코덱 지원에 따라 재생되지 않을 수 있습니다.

## 개선 사항
- 모바일 화면에 맞춘 반응형 UI
- 재생/일시정지/정지 및 채널 이동 동작 정리
- 재생 오류·네트워크 상태 안내
- 음량 및 음소거 제어
- 사용자 스트리밍 채널 추가/삭제와 브라우저 저장
- 잠금 화면/이어폰 미디어 버튼 지원(브라우저 지원 시)
- 실제 PWA 파일 구성 및 서비스 워커 캐시
- 스트리밍 오디오는 캐시하지 않으며, 앱 화면만 오프라인 캐시
